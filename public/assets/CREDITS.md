# Créditos dos assets

Os arquivos SVG em `sprites/` são placeholders originais, criados para este
projeto e sem recursos de terceiros:

- `player.svg` — personagem do jogador
- `enemy.svg` — robô inimigo
- `boss.svg` — chefe
- `bullet.svg` — projétil
- `wall.svg` — parede

Fonte: criação própria para o projeto TriggerHell. Não foram usados assets
externos.

As pastas `sounds/` e `tiles/` estão reservadas para assets adicionados em
outras tarefas.
